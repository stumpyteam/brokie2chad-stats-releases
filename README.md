# Brokie 2 Chad Stats: releases

Download builds of **Brokie 2 Chad Stats**, the Windows stats app for the Brokie 2 Chad YouTube and TikTok channel.

- Each version is a release here with `Brokie2ChadStats-<version>.exe` and `latest.json` (version, download link, SHA-256).
- The installed app checks `releases/latest/download/latest.json`, downloads the new .exe, checks its SHA-256 and restarts.
- The app holds no keys or account data; each user signs in to their own accounts on their own PC.
- Source code is private. Made by [Stumpy Team](https://stumpyteam.dev/). Privacy: https://stumpyteam.dev/brokie2chad-stats-privacy/
